# public/art

Imagens raster do jogo. Solte os arquivos gerados aqui.

**Piloto atual:** `field.png` — o terreno do campo de batalha (1280×720, 16:9).

Os prompts do Midjourney e as restrições que a imagem precisa respeitar estão em
[`docs/arte-raster.md`](../../docs/arte-raster.md).

Tudo em `public/` é copiado para o build como está — os arquivos ficam acessíveis
em `art/<nome>` e entram no APK. Sem imagem aqui, o jogo continua desenhando o
terreno proceduralmente.
